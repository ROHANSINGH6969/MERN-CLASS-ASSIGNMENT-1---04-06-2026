# MERN-CLASS-ASSIGNMENT-1---04-06-2026

## Responsive Landing Page Using HTML & CSS

This assignment demonstrates the development of a modern and responsive landing page using HTML5 and CSS3. The webpage is inspired by a professional Bootstrap-style landing page and includes a clean layout, attractive design, and mobile-friendly responsiveness.

## Features Implemented
## Header Section
Contains a website logo/title ("Start Bootstrap").
Includes a "Sign Up" button aligned to the right.
Uses Flexbox for proper alignment and spacing.

## Hero Section
Displays a full-width background image.
Includes a semi-transparent overlay to improve text visibility.
Features a large heading and an email signup form.
Uses CSS positioning and Flexbox for centering content.


## Signup Form

Allows users to enter an email address.
Includes a styled call-to-action button.
Designed with a responsive layout that adapts to smaller screens.
Features Section
Showcases three key features:
Fully Responsive
Bootstrap 5 Ready
Easy to Use
Uses Bootstrap Icons for visual representation.
Cards are arranged horizontally on larger screens and stack vertically on mobile devices.

## Responsive Design

Implemented using CSS media queries.
Ensures proper display on desktops, tablets, and smartphones.
Adjusts typography, form layout, and feature cards for better user experience.

## Technologies Used

HTML5, 
CSS3, 
Flexbox, 
Media Queries, 
Bootstrap Icons CDN

## Learning Outcomes

Understanding webpage structure using semantic HTML.
Applying CSS styling and layout techniques.
Using Flexbox for responsive alignment.
Creating responsive designs with media queries.
Integrating external icon libraries.
Building a professional landing page layout similar to real-world websites.

## Conclusion

This project successfully creates a visually appealing and responsive landing page that can be used for lead generation or product promotion. The design follows modern web development practices and provides a consistent user experience across different screen sizes.
